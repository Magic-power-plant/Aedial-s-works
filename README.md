# Aedial's Works

一个 Minecraft **1.20.1**（Forge）模组，将 **Aedial** 的三款 Applied Energistics 2 附属——**Cell Terminal**（元件终端）、**AE2 PowerTools**（电力工具）、**C.E.L.L.S.**（压缩元件）——合并移植到一个 jar 中，共新增 179 种物品（含 14 种机器方块、15 种线缆部件）和 194 个配方。

## 运行环境

- Minecraft 1.20.1
- Forge 47.4.10 及以上（47.x）
- [Applied Energistics 2](https://modrinth.com/mod/ae2) 15.x（会自带 GuideME）
- Java 17

安装方式：将本模组 jar 与 AE2 一起放入 `mods` 文件夹即可。

## Cell Terminal（元件终端）

在一个界面里管理整个 ME 网络中的所有存储元件。

- **元件总览**：按存储设备（ME Drive、ME Chest、Storage Bus）分组浏览网络中的所有元件，支持折叠/展开分组、双击定位元件在世界中的位置。
- **元件操作**：弹出、插入、交换元件；查看元件内容与分区；设置有符号优先级、模糊模式；插拔升级卡；集成 AE2 网络工具的工具箱。
- **高级搜索**：保留原模组的搜索解析器，支持内容/分区/混合模式、三态筛选、虚拟滚动、紧凑/加高布局。
- **子网浏览**：双向发现子网、星标收藏、多网络混合浏览、返回根网络；重开终端会恢复上次浏览的子网。
- **网络工具**：批量分区、按资源种类整理元件（整理失败不会部分提交），批量操作需五秒内双击确认，每次最多 256 个目标。

### 上手

1. 在线缆上放置**元件终端**部件并为网络供电，右键打开。
2. **无线元件终端**：先充电，按 AE2 的方式绑定**无线访问点**，然后右键物品或按 **Shift+P** 打开。范围与耗电遵循 AE2 无线终端规则。
3. 分区页中携带物品点击虚拟槽设置过滤，右键清空，Ctrl 点击优先采用容器内流体。
4. 界面共八个图标标签：元件、内容、分区、暂存、总线内容、总线分区、网络工具、子网；part 和无线终端各有独立的 16 格暂存区。

## PowerTools（电力工具）

面向中大型网络的自动化与诊断工具集：

- **等级维护器**：24 条资源配置，库存不足时自动请求 AE2 CPU 合成；支持批量、间隔、并发限制、CPU 重试与取消，合成链接在重启后自动恢复。
- **自动合成器**：12 个真实样板槽、4 个速度卡槽（四级速度卡）；使用真实配方合成，自动返还催化剂与容器；网络满仓时产物持久保存，恢复空间后重试。
- **监控与警报**：24 条物品/流体监控，支持 AND/OR、六种比较符、迟滞和 1–15 级红石输出；警报器向绑定玩家发送 HUD、世界高亮和方向提示。
- **诊断工具**：扫描器（六类网络诊断）、定位器（定位网络组件）、优先级调节器、分发器（把背包里的加速卡批量填入网络中的分子装配室）。
- **远程监视器**：绑定无线访问点后远程查看与配置，耗电与距离遵循 AE2 规则。
- 新增 `shapeless_reusable` 配方类型，支持合成台、自动合成器与 JEI 原版合成分类（催化剂可复用）。

## CELLS（压缩元件）

突破原版 AE2 元件容量上限的存储体系：

- **48 个元件与 45 个组件**：普通压缩、超高密度物品/流体/压缩、可配置及创造元件；单元件可存超过 2³¹ 数量，精确字节/类型计费，支持分区、无损压缩余数与组件交换。
- **8 种接口方块与对应部件**：物品/流体导入、导出、组合及 IO；容量卡可扩展至每端口 180 槽，支持自动拉推、保留量和传输间隔。
- **前后子网代理**：支持过滤、模糊、反相、优先级、插入卡，内置同网、循环、多跳与并行重复保护；Cell Terminal 可直接发现代理子网。
- **压缩样板暴露器**接入真实 AE2 CPU 参与自动合成。
- 24 张升级卡、22 种处理器材料、6 个压印器配方；原生 AE2 风格配置界面、记忆卡、热键、HUD、管理员命令和五层染色。

## 配置文件

- `config/aedialsworks-common.toml`：CELLS 元件可用性策略（不改变注册内容）。
- `<存档>/serverconfig/aedialsworks-server.toml`：服务端行为、权限、容量、能耗、轮询和网络参数，按存档加载并同步。
- `config/aedialsworks-client.toml`：高亮、搜索、筛选、选中页面和显示偏好（布局、内容上限、子网显示、收藏等）。
